# Beecrowd 1001 - Extremamente Básico

## Descrição

Solução do problema 1001 do Beecrowd.

O programa lê dois números inteiros e calcula a soma entre eles.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

Dois números inteiros.

## Saída

O programa exibe o resultado da soma no formato:

**X = resultado**
